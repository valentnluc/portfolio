# Montecarlo Simulation

A deep dive into probabilistic modeling for real estate investment risk assessment.

## Overview

This project implements Monte Carlo simulation techniques to model uncertainty in real estate development projects. By running thousands of simulations with varying input parameters, we can better understand the range of possible outcomes.

## Key Features

- **Stochastic modeling** of sales velocity and pricing
- **Fan charts** for visualizing confidence intervals
- **VAN/TIR distributions** with risk metrics
- **Sensitivity analysis** via bubble matrices
