# Earned Value Management

Tracking project performance through integrated cost and schedule metrics.

## The Problem

Traditional project tracking often separates cost and schedule reporting, making it difficult to understand true project health.

## Solution

EVM integrates scope, schedule, and cost data to provide a holistic view of project performance through metrics like:

- **CPI** - Cost Performance Index
- **SPI** - Schedule Performance Index  
- **EAC** - Estimate at Completion
- **VAC** - Variance at Completion
